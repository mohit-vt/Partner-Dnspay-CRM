Step by step installation

  1. Extract your downloaded file contens. You will notice a folder called "documentation" and a new zip file, called "upload.zip". We will focus on the "upload.zip" file
  2. Go to your Perfex CRM's Admin area and select the following menu item: SETUP > MODULES
  3. Find the newly installed module and press ACTIVATE

Upgrade Module

Download upgrade file from Codecanyon

Select upload module

If the version you have downloaded is larger than the current version, please click UPGRADE DATABASE (if available)

FAQS

1. I get an error when I try to upload the module at SETUP > MODULES

Hi, Maybe the problem is with the file upload_max_filesize, post_max_size of PHP. You can activate it manually by unzipping the module files (PerfexLanding) inside the ”/modules” folder of source code PerfexCRM
=> Then activate the module at module manager
